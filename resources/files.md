# 文件库

文件库用于集中查找和整理资料。个人文件属于个人范围，项目文件属于具体项目；进入前先确认自己要找哪一类材料。

例如，查找供应链整改证据时，应先选择“供应链运营协同”的项目库。只看文件名相同，无法判断它是否就是当前项目使用的那一份。

## 查找文件

1. 打开左侧「文件库」。窗口较窄时先展开「更多」。
2. 选择个人库或目标项目库。
3. 进入相关目录，使用页面现有的查找或浏览方式定位文件。
4. 打开文件，核对名称和内容。

从「我的项目」进入的同一项目文件，与文件库中的项目库对应同一范围，不需要另行维护一份同名资料。

## 预览与下载

预览用于在界面内查看内容；下载用于取得本地副本。需要把文件用于后续工作时，执行下载后应在实际下载位置打开检查。

外部链接和外部文件夹还受原平台账号与权限限制。看到一个入口，不代表其中全部内容已经同步到 Eva。

## 把会话附件整理到文件库

会话中的附件默认留在来源会话。需要集中存放时，使用相应附件的「保存到文件库」操作，选择有写入权限的目标库和目录，保存后到目标位置核对。

这一步需要同时满足来源可读、目标可写。保存后的库中文件与原会话附件分别管理，删除其中一份不会自动删除另一份。

::: tip 保存前检查接收范围
选择项目库时，先确认这份材料适合放入该项目。保存到目标库的文件按目标库权限使用；来源关联本身不授予查看原会话的权限。
:::

## 快捷方式

快捷方式是通向源文件的入口，方便从其他位置找到文件。它不复制源文件，也不扩大访问权限。

删除快捷方式不会删除源文件；源文件无法访问时，快捷方式也不能绕过限制。

## 访问问题

按顺序检查：

1. 是否选对个人库或项目库，以及目录。
2. 自己是否仍是项目成员。
3. 当前条目是实际文件、快捷方式，还是外部链接。
4. 如果是外部链接，原平台账号是否有访问权限。

置顶与快捷方式只便于查找，不授予新权限。本版的真实保存、公开分享及回收站范围见[适用范围](../help/scope.md)。
