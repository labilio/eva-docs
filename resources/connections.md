# 连接器

连接器用于管理 Eva 与外部资源的连接，例如邮箱、协作平台或本地资源。它帮助你明确可以访问什么，以及是否已完成相应授权。

例如，希望围绕邮箱中的材料工作时，除了提出要求，还需要相应连接和访问权限。仅在对话中提到邮箱名称，不会自动完成授权。

## 页面概览

| 分类 | 解决什么问题 | 怎样理解 |
| --- | --- | --- |
| 连接器 | 可以访问哪些资源 | 连接外部账号或资源的入口 |
| 技能 | 怎样处理某一类工作 | 工作方法与能力 |
| MCP 服务 | 有哪些可调用工具 | 向 AI 提供工具的服务 |

MCP 是工具接入协议的名称，服务说明中列出了可提供的工具及用途。

安装技能不自动连接外部账号。新增服务记录后，也要核对实际连接和工具状态。

## 连接器管理

1. 打开左侧「连接中心」，进入「连接器」分类。
2. 查看目标连接器的名称、用途和当前状态。
3. 需要连接时，打开对应入口，阅读授权范围。
4. 完成流程后，回到连接器列表核对状态。

::: info 当前为授权流程演示
原型授权弹窗标记为 Demo，不访问真实外部账号。请使用示例内容，不在演示表单填写真实密码或密钥。界面状态变化不证明外部服务已接通。
:::

## 断开连接

找到相应连接器，使用断开连接操作，再检查它的状态。正式服务中的授权撤销还需以相应平台的实际流程为准，本版不承诺演示操作会撤销真实平台权限。

## 查看技能

切到「技能」分类，先阅读能力介绍和安装状态。页面提供的新建、URL 导入用于体验管理流程，不表示已下载并执行远程内容。

想在个人对话中选用能力，继续阅读[技能](../personal/skills.md)。技能管理和对话中的技能选择是两个不同环节。

## 查看 MCP 服务

在 MCP 分类查看服务及工具说明。遇到实际服务无法连接时，需要核对地址、授权和可达性；修改显示名称不会解决连接问题。

对当前体验版的演示状态有疑问时，先查看[适用范围](../help/scope.md)，再记录连接器名称、操作步骤和提示内容反馈。
