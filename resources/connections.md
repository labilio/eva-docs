# 连接器

连接中心集中展示连接器、技能和 MCP 服务。三者分别管理资源连接、工作能力和可调用工具。

| 分类 | 用途 |
| --- | --- |
| 连接器 | 管理外部账号或资源的连接 |
| 技能 | 查看和管理处理某类工作的能力 |
| MCP 服务 | 查看通过工具接入协议提供的服务与工具 |

## 查看连接器

打开左侧「连接中心」，选择「连接器」分类，查看各连接器的用途和状态。

技能与连接器分别管理。安装技能不会自动授权访问外部账号。

## 管理技能

切换到「技能」分类，查看能力介绍和安装状态。对话中选择技能的操作见[技能](../personal/skills.md)。

## 查看 MCP 服务

切换到 MCP 分类，查看服务及其提供的工具说明。MCP 是工具接入协议，具体可用工具由对应服务提供。
