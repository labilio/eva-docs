# 技能

技能用于扩展 Eva 处理特定工作的能力，包括文档写作、数据分析和演示文稿制作。你可以在对话中选择技能，再提供本次工作的材料和要求。

## 概述

技能、个人助理和连接器分别用于配置工作能力、AI 身份与资源访问：

| 容易混淆的对象 | 含义 |
| --- | --- |
| 个人助理 | 你选择与之对话的 AI 身份 |
| 技能 | 处理某类工作的方法或能力 |
| 连接器 | 访问外部资源的连接与授权入口 |

选择写作技能不会自动获得邮箱、云盘或项目资料的访问权限。需要的材料仍需通过可用且已授权的方式提供。

## 使用技能

1. 打开「Eva 同学」，进入一段新对话或当前工作对话。
2. 在输入区输入 `@`，查看技能候选。
3. 选择适合的技能，再补充具体要求和材料。
4. 发送消息。

::: tip 两种 @ 的区别
个人 Eva 的技能选择器用于选择能力；团队群聊里的 @ 用于提及成员。请根据当前入口查看候选列表，不要把技能名当作群成员。
:::

## 管理技能

进入「连接中心」的「技能」分类，查看能力介绍和安装状态。需要添加时，先确认来源及用途，再使用页面提供的新建或导入入口。
