# 对话管理

分组是个人对话的文件夹。你可以按工作主题归类，例如“供应链运营协同”和“周报整理”，以后从分组中找回相关对话。

分组只整理对话，不建立项目成员关系，也不会读取同名电脑目录中的文件。

## 新建分组并开始对话

1. 打开左侧「Eva 同学」，点击中间栏右上角「新建分组」。
2. 在「分组名称」填写「周报整理」，点击「新建」。
3. 在列表中找到新分组，点击它右侧的加号。
4. 在右侧填写并发送需求。

发送后，这段对话会出现在「周报整理」下面。仅创建分组不会自动创建一段有内容的对话。

::: tip 暂时不需要分类
可以直接在固定的默认分类中开始，界面中显示为「最近」。以后再移动对话，不必重新发送原来的内容。
:::

## 重命名与移动

在对话行上打开右键菜单，选择重命名，输入能说明工作内容的名称，例如「九月供应商报价对比」。完成后，中间列表会显示新名称，历史内容保持不变。

需要更换分类时，在同一个右键菜单选择移动，再选择目标分组。移动后历史消息保留。

## 置顶常用分组与对话

分组右侧的更多菜单提供置顶或取消置顶；对话行的置顶操作在悬停或键盘聚焦时出现。

分组置顶方便你快速找到某类工作；对话置顶把常用对话排在所属分组前面。它们都只改变个人整理顺序。

## 删除分组与对话

| 操作 | 结果 |
| --- | --- |
| 删除普通分组 | 其中对话移回默认分类，继续保留 |
| 删除一段对话 | 删除该段历史，操作前按提示确认 |
| 删除或重命名默认分类 | 默认分类固定，不提供这两项操作 |

::: warning 删除对话前
先保存仍需要的文字或材料。删除分组与删除对话的结果不同，请核对确认框里的对象名称。
:::
