# 本版手册适用范围

本版依据 Eva Evolve 设计原型编写，面向首次使用 Eva 的普通用户，兼顾项目成员与负责人。它用于内部体验、内容评审及后续客户交付准备。

正文中的教程说明当前可以理解和体验的操作；真实模型、账号与数据服务仍需在正式交付环境中验证。

## 可以从手册学到什么

- 从发送需求到补充修改、检查结果、整理个人对话。
- 个人助理、云端分身、数字员工与 AI 小队的区别。
- 项目、群聊和子区如何组织团队工作。
- 创建项目任务、更新进度、查看子任务与附件。
- 文件库、技能、连接器与工具服务的基本用途。

教程使用现有“供应链运营协同”演示项目，并提供可复制的练习材料。文中明确标注的人工结果示例只用于教学，不作为原型实际生成结果的证据。

## 当前体验的边界

| 内容 | 当前范围 |
| --- | --- |
| AI 回复与产物 | 部分为模拟回执或预置演示，不能据此确认真实任务已执行 |
| 安装与账号 | 从进入工作界面后开始，不提供未经确认的安装包、注册或企业登录步骤 |
| 个人与团队数据 | 演示数据和浏览器本地状态为主，不提供完整跨设备同步承诺 |
| 项目任务与附件 | 部分只保留在当前页面，不应作为后端持久保存或可靠备份 |
| 连接器与导入 | 展示配置和授权流程，不证明真实外部账号连接或远程技能执行 |
| 自动化与站点发布 | 有设计入口，尚未纳入正式操作教程与服务承诺 |
| 文件管理 | 说明已明确的归属与访问边界，不推定完整公开分享、权限矩阵或回收站规则 |

体验时请使用示例材料，不把当前演示状态作为唯一工作记录。关于具体入口的疑问，可先查看[常见问题](./faq.md)。

## 正式交付时如何使用

需要以实际客户端核对菜单名称、操作截图、安装登录、数据保存、AI 执行及真实授权，再发布对应版本。手册中的成员规则与已确认功能，应与交付版本一同校验。

本版不包含运维部署、API、套餐价格或合规条款。第一次使用建议从[快速开始](../guide/quickstart.md)进入。
