# 关注与最近

「我的消息」提供「关注」和「最近」两种列表。关注按项目和群聊组织讨论，最近把不同项目的会话放在一起，方便按消息时间查找。

两处打开的是同一份会话。切换列表不会复制消息，也不会改变草稿、成员关系或访问权限。

## 两种列表的区别

| 对比 | 关注 | 最近 |
| --- | --- | --- |
| 组织方式 | 项目下展示群聊，群聊下展示子区；私聊和非项目群放入个人分组 | 跨项目展示会话，子区可以单独占一行 |
| 排序 | 可以拖动分类，以及分类内的群聊或私聊，保存个人顺序 | 置顶会话在顶部，其余会话按消息时间排列 |
| 项目范围 | 展示已关注项目中你有权访问的群聊 | 不要求先关注项目 |
| 所属位置 | 通过项目、群聊和子区的层级体现 | 项目群显示项目名；项目子区显示“项目 / 父群” |

最近列表中的子区仍属于原群，成员和权限不因单独显示而改变。

## 关注整个项目后会怎样

在「我的项目」的项目列表中，对目标项目使用「关注」。这项选择会同步到「我的消息」的关注列表。

关注项目后：

- **项目成为一个分类。** 其中展示你当前有权访问的全部群聊，包括全员群和已加入的普通群。
- **子区保留在所属群聊下面。** 不会变成独立项目，也不需要逐个关注；已隐藏的子区仍按个人隐藏设置处理。
- **群聊范围自动更新。** 之后新建或新获得访问权的群聊，会自动出现在该项目分类中，无需重新关注项目。
- **项目入口同步显示关注状态。** 项目目录与项目切换器使用同一份关注选择。切换器同时有已关注和未关注项目时，会分组展示。

关注不会把你加入尚未加入的普通群，也不会授予新的权限。即使是项目负责人或管理员，尚未加入的普通群也不会因为关注项目而开放。

例如，一个项目有全员群、采购群和质量群，你只加入了前两个群，关注后就会显示这两个群。以后加入质量群，它会自动出现在该项目分类中。

## 取消关注项目

在项目列表中使用「取消关注」，该项目分类会从消息的关注列表移除。项目目录和项目切换器中的关注状态也会同步更新。

取消关注不会退出项目或群聊，不会删除消息，也不等于免打扰。在仍有访问权的前提下，可以继续从最近列表、搜索或项目入口打开会话。

重新关注后，项目下当前可访问的群聊会重新列出。

## 整理关注列表

通过列表中的拖拽手柄，可以调整分类顺序，以及同一分类内群聊或私聊的顺序。子区随父群移动；拖动不会改变群聊的项目归属。

私聊和非项目群可以使用个人分组。右键点击会话，选择「移动到分组」或「新建分组」；未分配的会话放在默认的「其他会话」中。个人分组只影响自己的列表，不创建项目或群聊。

项目群不能移入个人分组。子区没有单独的关注入口，可通过置顶、隐藏或归档整理，见[子区管理](./messages.md#整理与管理子区)。

## 整理最近列表

右键点击最近列表中的会话，可以使用以下操作：

| 操作 | 效果 |
| --- | --- |
| 置顶／取消置顶 | 将会话固定在最近列表顶部，或恢复普通排序 |
| 清除未读 | 清除该会话当前的未读状态；有未读时才显示此操作 |
| 设为／取消免打扰 | 调整该会话的消息提醒 |
| 不显示该会话 | 从最近列表移除，并清除旧未读；保留聊天记录、成员关系及关注列表中的位置 |

使用「不显示该会话」后，搜索仍可找到它；新消息到来时，会话会重新出现在最近列表，并保留原来的置顶偏好。

::: tip “不显示该会话”和“隐藏子区”不同
“不显示该会话”只整理最近列表，新消息到来后会恢复。隐藏子区使用独立设置，普通新消息不会自动恢复，需从父群的「已隐藏」中找回。
:::

最近列表的会话置顶与父群内的「置顶子区」也分别管理：前者影响最近列表，后者只调整该父群内的子区顺序。
