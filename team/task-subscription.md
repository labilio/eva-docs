# 任务订阅

订阅可以把你想持续跟进的任务收进「我订阅的」，方便以后找到它。即使你不是任务创建者或负责人，只要能访问这个任务，也可以订阅。

::: info 当前原型范围
当前演示支持订阅、取消订阅和筛选查看，尚未提供任务更新通知或收件箱。订阅选择保存在当前浏览器，不支持跨设备同步。
:::

## 订阅一个任务 {#subscribe}

1. 打开任务详情，点击顶部的「订阅」。
2. 按钮变成「已订阅」，说明操作已经生效，无需再次确认。
3. 回到所属项目的任务页，点击「我订阅的」，即可集中查看已订阅任务。

例如，供应商整改由同事负责，但你需要在采购前确认结果。你可以订阅这项任务，之后从「我订阅的」打开它，查看最新状态和讨论。

![任务详情顶部的已订阅按钮](/images/task-subscription-header.png)

*「已订阅」表示你正在订阅当前任务，点击可取消。*

## 查看我订阅的任务 {#find}

「我订阅的」显示当前项目中你订阅的任务，包括手动订阅和自动订阅的任务。看板、表格、层级等视图共用同一份订阅关系，切换视图不会取消订阅。

在项目任务页右上角点击「使用帮助」，可以打开任务指南，再进入订阅说明。文档在新页面打开，原来的任务页面会保留。

顶部三个入口是快捷筛选：

| 入口 | 查看范围 |
| --- | --- |
| 全部任务 | 不限制负责人或订阅关系 |
| 我负责的 | 负责人是你本人的任务 |
| 我订阅的 | 你已订阅的任务，不要求你是负责人 |

切换这三个入口时，状态、优先级、关键词等其他筛选条件仍然保留。如果找不到某个已订阅任务，可以检查当前项目和其他筛选条件，或使用「清除筛选」。

## 为什么没有点订阅，也会显示已订阅？ {#automatic}

为了方便继续跟进与你有关的工作，以下情况会自动订阅对应任务：

- 你创建了任务，或被设为任务的创建者、来源者。
- 任务被指派给你。
- 你在任务中发表评论或回复。
- 任务描述或评论通过提及功能 @ 了你。仅输入你的姓名不算提及。

首次加载项目任务时，也会根据已有的上述关系补齐自动订阅，因此没有手动操作的任务也可能显示「已订阅」。自动订阅与手动订阅的查看方式相同，也都可以取消。

### 我的 AI 分身参与时呢？ {#avatar}

你自己的可用云端分身创建任务、被设为创建者或来源者、发表评论或回复、被提及时，自动订阅会归到你本人；同一任务只显示一次。你和分身都需要具有项目访问权限。

个人助理、数字员工和其他人的分身不按这条规则归到你名下。订阅不会把你设为负责人，也不会让分身开始执行任务。

## 取消订阅 {#unsubscribe}

打开任务详情，点击顶部的「已订阅」，按钮恢复为「订阅」。该任务会从你的订阅结果中移除，但任务内容、负责人和你的项目成员身份都不会改变。

**手动取消后，这个任务不会因为你再次评论、被指派或被 @ 而自动重新订阅。** 想继续跟进时，手动点击「订阅」即可恢复。

如果没有手动取消，任务转派给别人、删除原来的评论或移除提及，都不会撤销已经建立的订阅。

## 其他常见问题 {#faq}

### 订阅父任务后，子任务也会订阅吗？

不会。父任务与每个子任务分别订阅，需要跟进哪个任务，就订阅哪个任务。

### 订阅任务和关注项目有什么区别？

任务订阅帮助你在任务页集中查看具体工作。关注项目影响的是「我的消息」中项目和群聊的组织方式，两者独立。详见[关注与最近](./following-and-recent.md)。

### 离开项目后，订阅会保留吗？

失去项目访问权限后，原有订阅不再有效；重新加入项目不会恢复旧订阅。需要时可以重新手动订阅。

订阅不授予额外访问权限，也不能用来打开无权访问的任务。
