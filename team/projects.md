# 项目

项目集中组织团队成员、讨论、任务和资料。成员可以在项目群中沟通，通过任务记录责任分工与进度，并在项目文件库中查找资料。

例如，“供应链运营协同”把参与保供、采购和质量工作的成员组织在一起。群聊用于确认情况，项目任务用于记录谁负责、何时完成以及当前进度。

## 概述

| 内容 | 用来做什么 |
| --- | --- |
| 成员 | 确认谁参与当前项目 |
| 全员群与普通群 | 进行项目沟通，全员群覆盖项目成员，普通群有各自的成员范围 |
| 项目任务 | 持续跟进需要完成的事项 |
| 项目文件 | 集中查找属于该项目的资料 |

个人对话分组只整理自己的历史。即使分组与项目同名，也不会自动共享内容或成员。

## 打开并关注项目

1. 点击左侧「我的项目」。
2. 找到并打开你参与的项目。首次体验可使用「供应链运营协同」。
3. 核对项目名称，再进入任务、成员等内容。
4. 经常使用时，在项目列表使用「关注」。以后可通过消息的关注视图快速找到相关讨论。

取消关注只改变个人访问方式，不退出项目。部分界面说明使用“置顶”表示这一整理用途。

## 添加项目成员

开始前，对方需要是组织内已激活 Eva 的联系人。项目负责人、管理员和普通成员都可以添加合资格联系人。

1. 在当前项目打开成员管理。
2. 点击「添加成员」，搜索或选择需要加入的联系人。
3. 核对已选姓名，确认添加。
4. 回到成员列表，检查对方是否已出现。

添加成功后直接生效，对方自动加入项目全员群，无需再接受邀请。普通群仍单独维护成员，不会因为加入项目就全部加入。

::: tip 搜不到候选人
先检查对方是否已在项目中，再确认是否激活 Eva。搜索只查找当前可添加的联系人，不扩大候选范围。
:::

## AI 成员

本人加入项目不会自动带入分身。每位成员只能自行带入自己的分身；分身不继承主人的负责人或管理员权限。

数字员工通过其详情中的「加入项目」流程进入项目使用范围。个人助理则用于个人工作，不通过项目拉人流程加入。区别见[我的 Agent](../personal/my-ai.md)。

## 成员角色

负责人、管理员和普通成员决定管理权限；采购、质量等业务分工说明成员负责的工作。给成员设置业务角色，不等于授予管理员权限。

负责人或管理员需要调整业务角色时，在成员管理右上角、添加成员旁打开「角色设置」，选择成员并设置角色。任务的执行负责人则在具体任务中选择。

## 退出项目

项目负责人应先转让负责人，再退出。退出后，本人和分身会退出项目、全员群及项目普通群，失去相关子区和项目文件访问权。

::: warning 再次加入不会恢复全部关系
重新加入后，原普通群、管理角色和此前分身关系不会自动恢复，需要按当前规则重新设置。操作前先确认交接安排。
:::
