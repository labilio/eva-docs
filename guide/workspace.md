# 认识工作界面

第一次打开 Eva，先看左侧入口、中间列表和右侧内容。它们分别回答三个问题：我要做哪类工作、打开哪一项、现在正在处理什么。

![Eva 工作界面，左侧为功能导航，中间为分组与对话，右侧为当前内容](/images/personal.png)

## 左侧：选择工作入口

| 想做什么 | 入口 |
| --- | --- |
| 直接与 Eva 对话 | Eva 同学 |
| 选择助理、分身、数字员工或 AI 小队 | 我的 Agent |
| 与同事沟通，找回项目讨论 | 我的消息 |
| 查看项目与任务 | 我的项目 |
| 查找组织内联系人 | 通讯录 |
| 查找个人或项目资料 | 文件库 |
| 查看连接器、技能与工具服务 | 连接中心 |
| 浏览数字员工的能力 | 数字员工 |

窗口较窄时，部分入口会收进「更多」。找不到文件库等入口时，先展开它。「我的 Agent」在导航收起时简称「Agent」。

任务看板和自动化也有各自入口。本手册的项目任务教程从具体项目开始；自动化定时执行未纳入本版教程，参见[适用范围](../help/scope.md)。

## 中间：选择具体内容

中间列表随入口变化。在「Eva 同学」中，它显示分组和历史对话；在「我的 Agent」中，它显示 AI 身份与各自的对话；在「我的消息」中，它帮助你从关注或最近找到会话。

例如，要继续昨天的个人工作，应打开对应历史对话。仅切回「Eva 同学」入口，并不表示已经打开了昨天那一段。

## 右侧：完成当前操作

右侧展示当前选中的对话、项目或其他内容。发消息前先看标题，尤其是在多个项目群和 AI 对话之间切换时。

团队会话的输入提示会指明发送对象。项目子区还会显示父群与项目归属，可以用它确认自己在正确的讨论范围内。

## 同样叫“任务”，含义可能不同

“请 Eva 完成一项任务”通常是在描述一次工作请求；项目任务则是一条可以持续跟进的记录，有完整编号、状态和负责人。发出请求不会自动创建项目任务。

需要把工作纳入团队跟进时，阅读[项目任务](../team/tasks.md)。其他名词可在[术语速查](../help/glossary.md)中查找。
