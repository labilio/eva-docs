# 认识工作界面

Eva 的左侧导航用于切换工作入口。对话页面的中间列表用于选择会话，右侧显示当前内容。

## 功能导航

| 入口 | 内容 |
| --- | --- |
| Eva 同学 | 个人对话、分组和技能选择 |
| 我的 Agent | AI 身份单聊与 AI 小队 |
| 我的消息 | 联系人私聊、群聊与子区 |
| 我的项目 | 项目成员、任务、群聊与文件 |
| 通讯录 | 组织内联系人及对应的 AI 分身 |
| 文件库 | 个人资料与项目资料 |
| 连接中心 | 连接器、技能与 MCP 服务 |
| 数字员工市场 | 数字员工的能力介绍及加入入口 |

导航收起时，「我的 Agent」显示为「Agent」。

## 会话列表

- **Eva 同学**：按分组组织历史对话。
- **我的 Agent**：上方为 AI 小队，下方按分身、个人助理和数字员工组织单聊。
- **我的消息**：「关注」按项目和群组织讨论，「最近」按近期会话查找消息。

## 对话与项目内容

对话页面右侧包含消息和输入区；子区标题同时显示所属群与子区名称。

进入项目后，通过「任务」「群聊」「文件」「自动化」「项目信息」「项目设置」切换内容。项目成员和专家等配置位于项目设置中，具体操作见[项目](../team/projects.md)。
